## Release checks
Run repository gates and independent review at the integrated SHA. Verify both root token files return exact bytes and HTTP 200 on branded production, crawlable pages/links and assets work, mobile widths and focus, embed on a separate origin, analytics receipt and privacy opt-out. Do not change launch date or official content. Do not publish before required release gates pass.

### Capture a real gameplay asset
With a local preview running, use `node scripts/media/capture.mjs`. The script blocks off-origin requests, analytics, score APIs and non-read requests. It uses fresh browser contexts and the four canonical evergreen examples, verifies the exact teaching ID and prompt before every capture, and produces 12 portrait, 4 square and 4 landscape PNG candidates in a unique `build/media-review/capture-*` folder. Social dimensions use uniform fitting, not stretching. Use `MEDIA_VIDEO=1 node scripts/media/capture.mjs` for five optional local WebM recordings (Playwright video support required). The recording is the actual teaching UI, including a miss. It is not a demonstration of a full daily/weekly result. Any failed run deletes its unapproved candidate directory. The review manifest marks all entries pending and spoiler-safe false until manual approval. Inspect every image and the entire recording for clipping, readability, spoilers, actual timing and privacy; discard failures. Only then copy approved assets to `public/media/` and update the public manifest and page with real dimensions, size, source, alt text, review date and approval. The public library still contains only brand assets; this script has not yet run in the available environment. Daily and weekly demonstration score cards remain outstanding.

### Publisher configurator (staged)
The responsive snippet includes a visible new-tab attribution link; height is bounded to 600–1400 px. The width/height preview is deliberately illustrative, not a live iframe, so opening the configuration page cannot auto-resume a timed game or contaminate official events. The separate-origin Playwright fixture exercises the actual generated iframe against the isolated local game. Clipboard permission failures select the code for manual copying. WordPress and Ghost instructions reference their official help pages, including WordPress.com plan limitations and Ghost email limitations. The embed channel is fixed; no per-publisher identifier or new tracking. No CSP/header changes.
