# Stat Window launch kit

See [the launch runbook](LAUNCH.md) for the production schedule. Use the owner outreach package for contact routes, platform rules and approved drafts.

Draft copy for the owner to post by hand. Every public link uses `https://www.statwindow.app/`. Check each platform's current rules before posting; some communities ban self-promotion.

Facts every draft relies on (keep them true): free, no account, five NBA questions a day, the same five for everyone, three question formats (recall, reference, missing point), a 24-second clock per question, a window you drag around your guess (tighter and correct scores more, up to 100 a question and 500 a day), a new game at midnight Eastern. Official season starts Saturday, November 28, 2026 as Game 1.

Never put an answer or a question's number in a post. Scores and the colored squares are fine.
