# V5.0: question variety and the friend race

V5.0 adds two things. The rules of the game (5 questions, brackets, scoring, the 24 second clock, 500 max) stay the same.

1. **Question formats.** The NBA question factory can now write seven kinds of question. A launch audit reviewed every future slate.
2. **Friend race.** A challenge link can carry the sender's five round scores. The person who opens it races them round by round on the Live Court Run.

## 1. Question formats

| Format | What the player estimates | Data the factory needs (`question.format` in `data/nba/facts.json`) |
| --- | --- | --- |
| `recall` | a number from memory | nothing (this is the default, and the field is left out) |
| `reference` | a number, with another verified figure printed as an anchor | `references: [factId]`. Each figure must appear in the prompt or context |
| `missing-point` | the hidden column of a small chart | `chart: {title, unit, points: [{label, fact}]}`. Exactly one point is the question's own fact. Every point shares its unit and stat family |
| `difference` | the gap between two verified figures | `derive: {op: 'difference', of: [a, b]}` or `values: [x, y]` printed in the fact's own quote |
| `ratio` | a share or percentage | `derive: {op: 'percent', ...}` |
| `ranking` | a place in an ordered list | `ranking: {population, ties}` |
| `trajectory` | a career or era total built from parts | `derive: {op: 'sum', ...}` |

- **Answers are recomputed.** For derived formats, `formatIssues` (`scripts/nba/formats.ts`) recomputes the answer at the question's step. The fact's `source.derivation` must show the operands.
- **Metadata.** Days from `V5_CONTENT_FROM` (2026-11-28) on carry `meta: {format, family, era, subjects, supports}`, plus `chart` for missing-point questions. The V5.1 Scouting Report will read this metadata.
  - Earlier days are built without it, so their published bytes and lock fingerprints do not change.
  - `src/content/schema.ts` checks the shape. A chart hides exactly one value (null), and a chart and the missing-point format always come together.
- **No early spoilers.**
  - `validateNba` refuses any support (reference, chart point or derivation operand) that is played as a daily on the same day or later.
  - The Survival leak horizon (`survival.ts`) counts supports as leaks too.
- **The chart hides the answer** (`src/ui/QuestionChart.tsx`).
  - Columns are scaled from 0 to the question's `max`, not to the answer, and the hidden column is a dashed "?" slot.
  - The bracket band tracks the window with no easing.
  - On reveal the answer column grows with the ruler's own reveal progress. Nothing new moves, and Next and the clock are never delayed.

### Reserve embargo policy

`calendar.reserveNotBefore` only controls when a reserve question may appear in **Survival**. A daily may print a figure whose fact sits in the reserve, for example as a reference or a chart point. It is the daily that makes the figure public. The leak horizon then holds the reserve back from Survival, so it cannot be asked as a question after its answer has been shown.

- Each editorial batch file lists one decision per slot: `retained`, `reframed` (a format or wording patch on the same fact) or `replaced` (a new fact).

## 3. Friend race (challenge link v2)

**Link format.** `/?day=2026-11-16&vs=247&time=61000&v=2&r=48.61.0.100.38`

| Parameter | Meaning |
| --- | --- |
| `day` | the puzzle day. It must be a real, published, non-future day. A second copy of `day` makes the whole link invalid |
| `vs` | the sender's total, 0 to 500 |
| `time` | the sender's answer time in ms, up to 120000 |
| `v=2` | the link version |
| `r` | exactly five dot-separated whole numbers from 0 to 100, with no leading zeros. They must add up to `vs` |

**Legacy and broken links.**
- A link with no `v` and no `r` is a legacy link. It keeps the final-total comparison.
- Any of the following drops every friend score but still opens the same five questions:
  - an unknown `v`
  - `r` without `v=2`
  - a malformed `r`
  - a sum that does not match `vs`
  - a duplicated `vs`, `time`, `v` or `r`
  - a query over 600 characters

**What the link carries.**
- Only six small numbers. No answers, windows, question text or IDs.
- The numbers are not verified, so the copy never calls them verified or secret.
- Analytics still drop the query string. `challenge_open` adds a `/with-rounds` path segment.

**On the court.**
- The friend is an ink pin under the route. It is not a ball, so there are never three look-alike balls.
- The pin sits at the friend's total for the rounds the player has already finished. After round n it shows only the friend's first n rounds.
- A compact line under the court reads like "Friend 109 · you trail by 9".
- The pin and the line move after the player's ball lands, so one thing moves at a time. They do not move with reduced motion. Screen readers hear the standing on each reveal.

**Results.**
- A headline: You won by N, Your friend won by N, or Tie at N.
- Time breaks a tie only when both answer times are known.
- A table compares all five rounds side by side, followed by one true highlight from `raceHighlight`, or none.
- The recipient's own share link is a v2 link too.
