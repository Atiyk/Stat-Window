Where to paste it

WordPress

Add a Custom HTML block, paste the code and preview the published page. Self-hosted sites may restrict HTML by role or security settings. WordPress.com requires a plugin-enabled plan and activated hosting features for iframes. Sites without iframe support can use the game link. Custom HTML block · WordPress.com hosting requirements.

Ghost

Insert an HTML card in the editor and paste the code. Preview the web post. For the emailed newsletter, add a linked image or a text link to the game. Ghost HTML cards · Ghost email guidance.

Other websites and newsletters

Paste the HTML in a page template where iframes are permitted. For email, use this spoiler-free image linked to the daily game. No account or integration token is required by Stat Window.

Integration notes

  • Include a visible attribution link to Stat Window and an option to open the game in a new tab.
  • Test the published embed on a phone and desktop. Set the height so players can comfortably reach the answers and results.
  • Browser privacy settings may limit storage and sharing inside cross-site frames. If progress will not save or sharing fails, players can open the full game in a new tab. Their progress may be separate there.
  • Do not proxy, rehost, alter game assets or expose puzzle answers. Keep the original game URL.
  • Stat Window is independent and not affiliated with the NBA.
