Where to paste it

WordPress

Add a Custom HTML block, paste the code and preview the published page. Self-hosted sites may restrict HTML by role or security settings. On WordPress.com, iframe code requires a paid plan with hosting features activated; use the link option if your existing plan does not allow it. WordPress instructions.

Ghost

Insert an HTML card in the editor and paste the code. Preview the web post. Interactive embeds do not reliably work in email newsletters; use the linked image or text link below instead. Ghost HTML cards · Ghost email guidance.

Other websites and newsletters

Paste the HTML in a page template where iframes are permitted. For email, use this spoiler-free image linked to the daily game. No account or integration token is required by Stat Window.

Integration notes

  • Include a visible attribution link to Stat Window and an option to open the game in a new tab.
  • Test the embed on a phone and desktop. Avoid a fixed narrow frame or clipping the answer and results.
  • Browser privacy settings may limit storage and sharing inside cross-site frames. If a player cannot save progress or share, suggest opening the full game in a new tab. The iframe permissions shown are requests, not guarantees.
  • Do not proxy, rehost, alter game assets or expose puzzle answers. Keep the original game URL.
  • Stat Window is independent and not affiliated with the NBA.

For a newsletter that does not support iframes, link directly to today’s game.
