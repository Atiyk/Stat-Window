Privacy

Stat Window · last updated 22 November 2026

What Stat Window collects

Stat Window has no accounts, no ads, no tracking cookies and no third-party marketing pixels. Your game history (rounds, scores, streaks, settings) is saved in your own browser (localStorage) and never uploaded.

The daily shot clock also keeps a start timestamp in browser session storage and, for an unfinished official daily question, local storage so opening another tab does not give an extra 24 seconds. That timestamp stays on this device, is never sent to us, and is cleared when you lock or time out a question. An abandoned round's timestamp can remain until you clear site data.

We do not sell or share this data, build profiles, track you across sites, or fingerprint your device. A browser is not a person: we cannot link your phone and laptop, and we never claim to.

Global rankings (deferred, not part of V3)

Joining the public global leaderboard is a separate explicit choice. The game would send your five locked windows and a random browser code to re-score the official puzzle. The server would keep a pseudonymous score linked to a salted hash of that code until 30 days after each day, week, month or 120-day season ranking period ends. Linked daily records are partitioned into 120-day blocks and expire after their last potentially retained ranking; continued play does not extend older blocks; other players could see your generated nickname and score in day, week, month and season standings. A browser with a previous enrollment code can request deletion in the in-app Privacy and your data dialog without completing a new game or opening public rankings. Request deletion before clearing this site's data: clearing browser storage first loses the random code needed to remove those entries, so they may stay publicly listed until their normal expiry. If deletion fails or is rate-limited, new submissions stop immediately in this browser, but the random code is kept only for deletion retry, including after reload. Your ranking may remain public until deletion succeeds or expires; do not clear this site's data before a confirmed deletion. A failed deletion is never reported as successful. After a successful deletion, a nonpublic hashed browser-code revocation marker (no scores or raw code) is retained for up to 48 hours solely to block delayed score submissions. Live rankings are deferred and unavailable in V3. New enrollment and public boards are disabled. No historical leaderboard enrollment count has been independently verified; an absence of current activation environment variables does not prove historical absence. If any previous scores exist, independent safe erasure must be established before release. A disabled server may reject deletion; the browser keeps the code and truthfully reports that removal is not confirmed.

Your choices

  • Turn either off any time: the "Privacy and your data" button on the results screen, or "Privacy choices" in How it works. Turning analytics off takes effect immediately.
  • Global Privacy Control / Do Not Track: if your browser sends either signal, both start off. Analytics stays off; the results screen asks before adding your score. You can still switch either on yourself.
  • EU, EEA, UK and Switzerland: your score is only added after you tap "Count my score" (the server checks the country of the request, which it does not store). If the location is unknown we ask too. Before you answer, the app sends only today's date to ask whether a yes is needed: no code is created and your windows are not sent.
  • Delete my scores: immediately stops new submissions and requests erasure of any scores still linked to this browser code. Only an explicit valid server confirmation lets the browser clear the old code; a new random code is created only after a later permitted score submission, and the optional comparison remains off until you turn it back on. On a failed or unclear response, no deletion is claimed; the original code and submitted-day history remain for retry, and new submissions remain blocked. After confirmed deletion, the server keeps a nonpublic HMAC-only marker for up to 9 days to reject delayed submissions under the deleted code. It contains no score, IP address or raw browser code. Clearing this site's data before a confirmed response may lose the code needed to retry.
  • Daily calendar reminder: the results screen offers a repeating event for your own calendar, at the same New York (US Eastern) hour each day, like the puzzle, which opens at midnight New York time. The .ics file is static and the same for everyone who picks that hour; fetching it is an ordinary request to our host (Vercel), like loading the page. The Google Calendar link opens Google with fixed text, that hour and the New York time zone (never yours), and Google's own policy applies there. The app doesn't store whether you added a reminder. Opening the game from the event adds one dated entry to the app's existing list of counts already sent today, so it is counted once a day. We only count taps on the links and opens from the event, and only if play counts are on. Delete the event in your calendar to stop.
  • Gameplay never depends on either: if they are blocked, offline or off, the game works the same.

Children

Stat Window is a general-audience sports game and is not directed at children under 13. It collects no names, emails or contact details from anyone.
